# ДентаПро — лендинг стоматологической клиники

Этапы 1–2: адаптивный лендинг, каталог услуг, четырёхшаговый квиз с подарком, сравнение «До/После», врачи, отзывы, FAQ, схема проезда и запись в Telegram. Нативные HTML/CSS/JavaScript; сервер использует встроенный `fetch`, npm-зависимостей нет.

## Загрузка на Vercel

1. Создайте GitHub-репозиторий и загрузите `index.html`, `style.css`, `script.js`, папки `api` и `assets`, `vercel.json`, `.gitignore`, `.env.example` и этот README. Не загружайте `.env`. Перед каждым `git push` проверьте проект на секреты.
2. В Vercel выберите **Add New → Project**, импортируйте репозиторий.
3. Выберите Framework Preset **Other**. Root Directory — папка с `index.html`. Build Command и Output Directory оставьте без переопределения: сборка не требуется. Используйте актуальный поддерживаемый Node.js (22 или новее).
4. В **Settings → Environment Variables** добавьте `BOT_TOKEN` (токен бота) и `CHAT_ID` (идентификатор чата получателя). Для работы в тестовых деплоях добавьте переменные и в окружение Preview. Значения должны храниться только в настройках Vercel, не в исходниках.
5. Нажмите **Deploy**. После изменения переменных окружения выполните Redeploy.
6. Начните диалог с ботом или добавьте его в нужный чат с правом отправки сообщений. На сайте отправьте тестовую заявку и убедитесь, что она пришла в Telegram. Затем проверьте запись со смартфона.

Серверная функция доступна по адресу `/api/send`. Она принимает только POST JSON, проверяет имя, телефон, услугу и согласие. Для квиза (`type: "quiz"`) дополнительно проверяет все три ответа `answers.task`, `answers.pain`, `answers.payment` по списку разрешённых вариантов и включает их в сообщение Telegram вместе с подарком. Обычные заявки продолжают работать в прежнем формате. Заполненный honeypot `website` получает ответ 200 без отправки сообщения. Ошибки Telegram и секреты не передаются клиенту. При отсутствии переменных форма показывает ошибку, а не ложное подтверждение.

## Локальный просмотр

Для просмотра вёрстки откройте `index.html` в браузере. Отправка формы при открытии файла работать не будет — для неё нужен сервер.

Для проверки формы установите Node.js и Vercel CLI. Создайте `.env` по образцу `.env.example` и заполните его локально:

```text
BOT_TOKEN=
CHAT_ID=
```

В терминале из папки проекта запустите `npx vercel dev`. При первом запуске CLI предложит связать папку с вашим Vercel-проектом. Откройте адрес, напечатанный CLI. `.env` и `.vercel/` уже исключены из Git. Не публикуйте скриншоты и вывод команд со значениями переменных.

## Что заменить перед коммерческим запуском

- Подтвердите телефон, адрес, график, прайс, лицензию, рейтинг, гарантии, рассрочку и сведения о пациентах: сейчас используются данные из задания и демонстрационный прайс.
- Замените фотографию-плейсхолдер Unsplash на собственную. Шрифты Google Fonts загружаются через интернет. Plus Jakarta Sans используется с Inter как резервом для кириллицы.
- Замените демонстрационный текст политики в `index.html` на утверждённую политику с реквизитами оператора и условиями обработки данных, включая передачу через Telegram. На реальном домене настройте необходимые меры против массовых запросов; honeypot не заменяет ограничение частоты на уровне хостинга.
- Замените демонстрационные профили врачей и стоковые портреты на данные сотрудников; отзывы и рейтинги — на подтверждённые материалы. Работы представлены авторскими SVG-иллюстрациями, не реальными клиническими случаями; замените их парными фотографиями с согласия пациентов.
- Подтвердите условия бесплатного КТ и плана лечения. Квиз собирает заявку на ориентировочную смету, не ставит диагноз и не вычисляет окончательную цену. Ответ о дискомфорте передаётся в Telegram: до сбора реальных заявок утвердите необходимые условия обработки таких данных.
- Карта является схемой, не точной географической привязкой. Проверьте адрес и ссылку маршрута в Яндекс.Картах.

## Файлы

`index.html` — разметка и модальные окна; `style.css` — адаптивные стили; `script.js` — вкладки, общая маска телефона, квиз, сравнения, FAQ и формы; `assets/` — парные SVG-иллюстрации; `api/send.js` — серверная отправка; `vercel.json` — ограничения функции и заголовки безопасности. Поддерживаются клавиатурная навигация вкладок, управление фокусом в диалогах и уменьшение анимаций по настройке устройства. Заявки и ключи в браузере не сохраняются.

Уведомление о cookie появляется при первом посещении. Кнопка «Понятно» сохраняет только отметку закрытия в техническом cookie на 180 дней. Ссылка открывает существующую политику конфиденциальности. Аналитика не подключена. Если cookie заблокированы, закрытие работает до перезагрузки страницы.

Фотография первого экрана хранится локально в `assets/clinic.webp` (источник: Unsplash, фото `1629909613654-28e377c37b09`). Она загружается вместе с сайтом и не зависит от доступности Unsplash у посетителя. При публикации обязательно включайте всю папку `assets/`. Портреты врачей пока загружаются с Unsplash.
